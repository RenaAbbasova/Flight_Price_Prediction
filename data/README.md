# Data

The data file (about 23 MB) is not stored in this repository.

Download `Clean_Dataset.csv` from the Kaggle dataset **Flight Price Prediction** (Shubham Bathwal):
https://www.kaggle.com/datasets/shubhambathwal/flight-price-prediction

and put it in this folder as `data/Clean_Dataset.csv`.

It has 300,153 rows: flight bookings scraped from EaseMyTrip between 11 February and 31 March 2022, with the columns `airline`, `flight`,
`source_city`, `departure_time`, `stops`, `arrival_time`, `destination_city`, `class`, `duration`, `days_left` and `price` (in Indian rupees).
